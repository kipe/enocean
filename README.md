# Python EnOcean (archived)

**This repository is archived.** Development and maintenance continue at
[ChristopheHD/enocean](https://github.com/ChristopheHD/enocean).

The PyPI package name remains [`enocean`](https://pypi.org/project/enocean/)
(`pip install enocean`). Ownership of that project is transferring to the new
maintainer; installs are unchanged.

See [ChristopheHD/enocean#34](https://github.com/ChristopheHD/enocean/issues/34)
for the handoff discussion.

A Python library for reading and controlling [EnOcean](http://www.enocean.com/) devices.
Started as a part of the [Forget Me Not](http://www.element14.com/community/community/design-challenges/forget-me-not)
design challenge @ [element14](http://www.element14.com/).
